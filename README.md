One funny line pitching a terrible pizza topping: the chef's new special, a pizza
topped with pickled gummy bears. The joke lands in the second half — the bears
squeak when you chew them, and the brine doubles as a dipping sauce — which is
exactly the kind of practical selling point a proud chef would offer for a topping
nobody should ever eat.

## The entry

> Our chef's new special: pizza topped with pickled gummy bears — they squeak when you chew, and the brine doubles as a dipping sauce.

## How it works

Run `node main.ts` (Node 22 or later). It writes the single line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), after a length gate that
throws unless the line is 1–200 characters. No network, no randomness — the
output is fully deterministic.
